# QR Tools

QRコードの規格外な多重化を試す実験用Reactアプリです。実運用向けではなく、検証・デモ用途のPoCとして扱ってください。

## Modes

起動時のURLパラメータで機能を切り替えます。

- `?mode=dual` - 2つのURLを1枚に重ねる2URL QR生成
- `?mode=color` - RGBチャンネルに3つのURLを重ねるカラーQR生成
- `?mode=reader` - カラーQRをカメラまたは画像から読み取り

`mode` の代わりに `app` パラメータも使えます。

## Notes

2URL QRは、2つのQRコードの同じモジュール位置を比較し、値が違うセルだけを左/右強調・垂直・水平・対角・チェッカーボードのいずれかで分割して描画します。左からURL 1、右からURL 2を狙う場合は `Left/Right Strong` を使います。このモードではセルを大きくし、QRマスクを固定し、検出用の予約パターンを単色に保ちます。

`checkerboard` は本家にはない追加パターンです。現在の2URL QR生成では、過去の `bk_App.jsx` と同じく通常セルサイズ、固定マスクなし、セル内2×2の対角配置で描画します。実機で左右が逆に感じる場合は `Invert Pixel Splitting` を使います。

2URL QRは標準QRの仕様外のため、どの標準カメラアプリでも完全に左右が保証されるものではありません。画面で読み取る場合はQRをできるだけ大きく表示し、真正面ではなく明確に左側/右側から読むほど分離しやすくなります。

カラーQRはRed/Green/Blue各チャンネルを個別のQRとして扱います。`reader` モードではカメラ画像をRGBチャンネルに分離し、それぞれをQRとして読み取ります。

スマホでカラーQRリーダーのカメラを使う場合、ページはHTTPSで開く必要があります。PCのローカルIPを `http://...` で開いた場合はブラウザがカメラAPIをブロックするため、HTTPSの公開URLを使うか、リーダー内の「写真を撮って読む」を使います。HTTPSで開けている場合、リーダーは背面カメラを優先して起動します。端末やブラウザが背面指定を無視する場合は「カメラ切替」で使用カメラを切り替えます。
